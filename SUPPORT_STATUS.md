# Repository Support Status

Oscillate Labs repositories use a support status system to set clear expectations for users and contributors.

## Status Levels

### ![Active](https://img.shields.io/badge/status-active-brightgreen) Active

The project is under active development.

- New features and improvements are being worked on
- Bug reports and feature requests are welcome
- Pull requests are reviewed and merged regularly
- Dependencies are kept up to date

### ![Security Fixes Only](https://img.shields.io/badge/status-security%20fixes%20only-yellow) Security Fixes Only

The project is in maintenance mode.

- No new features will be added proactively, but pull requests are always welcome
- Only security vulnerabilities and critical bugs will be addressed
- Pull requests for security fixes are welcome
- Dependency updates are limited to security patches
- Consider this stable but not evolving

### ![Proof of Concept](https://img.shields.io/badge/status-proof%20of%20concept-orange) Proof of Concept

The project is experimental or a demonstration.

- Not recommended for production use
- May be incomplete, unstable, or abandoned
- Issues and PRs may not receive responses
- Provided as-is for learning or inspiration
- Could be promoted to Active if there's interest and time
